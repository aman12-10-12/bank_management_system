# Bank Management System

A modern **Bank Management System** built using **Python**, **Object-Oriented Programming (OOP)**, **JSON Database Handling**, and **Streamlit** for an interactive web interface.

This project allows users to create and manage bank accounts with features like secure login, money deposit, withdrawal, account updates, and account deletion.

---

# Features

- Create New Bank Account
- Secure Login using Account Number & PIN
- View Account Details
- Check Account Balance
- Deposit Money
- Withdraw Money
- Update Account Details
- Update Account PIN
- Delete Account
- Logout System
- Persistent Data Storage using JSON
- Interactive Streamlit Web Interface

# Installation

## 1️. Clone Repository

```bash
https://github.com/aman12-10-12/bank_management_system.git
```

---

## 2️. Open Project Folder

```bash
cd bank_management_system
```

---

## 3️. Create Virtual Environment

### Mac/Linux

```bash
python3 -m venv venv
source venv/bin/activate
```

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

---

## 4️. Install Dependencies

```bash
pip install streamlit
```

OR

```bash
python3 -m pip install streamlit
```

---

# ▶ Run The Project

```bash
streamlit run app.py
```

If the above command does not work:

```bash
python3 -m streamlit run app.py
```

# Note : 
```
Rename sample_bankData.json to bankData.json before running the project.
```
